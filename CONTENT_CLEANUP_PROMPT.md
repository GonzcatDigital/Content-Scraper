## Cleanup Rules

### 1. Frontmatter Standardisation

**Review and fix each frontmatter field:**

- **Titles**: Remove extra whitespace, fix double spaces, ensure consistent casing
- **Descriptions**: If empty/null, write a compelling 150-160 character meta description based on the content
- **Dates**: Convert verbose formats (ISO with timezone) to simple `YYYY-MM-DD` if desired
- **Alt text**: If `imageAlt` duplicates the title, write a proper descriptive alt text
- **Null values**: Either populate with real content or remove the field entirely

**Add any missing fields that would improve the content** (e.g., venue, location, tags) by extracting information from the body content.

### 2. Remove Scraping Artifacts

**Common WordPress/theme artifacts:**

```markdown
<!-- JavaScript remnants - delete lines matching this pattern -->
UNCODE.initRow(document.getElementById("script-XXXXX"));
[Any other JS initialization code]
```

### 3. Fix Markdown Structure

**Heading hierarchy:**
- `#` (h1): Never use in body - title is in frontmatter
- `##` (h2): Main sections only
- `###` (h3): Subsections
- Never skip levels (no h2 → h4)

**Common issues to fix:**

```markdown
<!-- Empty headings - delete -->
## 

<!-- Bold inside headings - remove bold -->
## **Heading Text**  →  ## Heading Text

<!-- Wrong heading level for non-hierarchical content -->
###### Share this post  →  [delete entirely]

<!-- Consecutive empty/duplicate headings -->
## 
## Actual Heading  →  ## Actual Heading
```

### 4. Image Cleanup

**Alt text requirements:**
- Every image MUST have descriptive alt text
- Describe what's visible in the image
- Keep under 125 characters
- Make relevant to the surrounding content context

**Fix these patterns:**

```markdown
<!-- Empty alt - add description based on context -->
![](/assets/uploads/image.jpg)
→ ![descriptive alt text based on surrounding content](/assets/uploads/image.jpg)

<!-- Filename as alt - replace with description -->
![IMG_20250726_145242](/assets/uploads/image.jpg)
→ ![relevant description](/assets/uploads/image.jpg)

<!-- Irrelevant/wrong alt - correct it -->
![wrong location or subject](/assets/uploads/image.jpg)
→ ![accurate description](/assets/uploads/image.jpg)
```

**Remote images:**
- Flag any images still using `http://` or `https://` URLs
- Add comment: `<!-- TODO: Remote image needs downloading -->`

### 5. Link Formatting

**Clean up link styling:**

```markdown
<!-- Remove unnecessary bold from link text -->
[**Link Text**](url)  →  [Link Text](url)

<!-- Keep bold if surrounding context is bold -->
**Label:** [Link Text](url)  →  [keep as-is]
```

### 6. Content Quality

**Text cleanup:**
- Fix typos (their/there, were/where, etc.)
- Remove double spaces
- Add missing spaces after punctuation
- Ensure blank lines between paragraphs
- Ensure blank lines before/after images

**SEO keyword stuffing:**
- Identify and reduce excessive keyword repetition
- Keep 1-2 natural mentions, remove forced variations

**Readability:**
- Break up very long paragraphs (>5 sentences)
- Ensure logical content flow

### 7. Structured Sections

**If the content has vendor credits, supplier lists, or similar structured data**, standardise the format:

```markdown
## Section Title

- **Label:** [Link Text](url)
- **Label:** Text value
- **Label:** [Link Text](url)
```

### 8. Calls to Action

- Keep existing CTAs but clean up formatting
- Remove outdated URLs or references to old site
- Don't create new CTAs that weren't there

## Output Format

For each file processed, provide:

1. **Filename:** `slug.md`
2. **Changes Made:** Bullet list of significant changes
3. **Full Cleaned Content:** The complete cleaned markdown file
4. **Flags:** Any issues requiring human review (remote images, unclear content, etc.)

---

## Processing Instructions

1. **Process files one at a time** to maintain focus and accuracy
2. **Read full content first** to understand context before making changes
3. **Preserve authentic voice** - don't rewrite the content, just clean it
4. **Don't add content** that wasn't in the original
5. **Use context for alt text** - base descriptions on surrounding paragraphs
6. **Flag uncertainties** - if something needs human review, say so
7. **Be consistent** - apply the same fixes across all files
